TINY TREK STUDIO WEBSITE
========================

This revision removes the small numbered section labels such as "01 Latest Release", "02 What We Do", "03 Selected Work", etc.

The service list under "FROM FIRST PROTOTYPE TO PLAYABLE RELEASE" has also been simplified:
- no 01 / 02 / 03 / 04 numbers
- no arrow icons on the right
- the service rows remain interactive with a subtle hover response

FILES
-----
index.html               Main studio website
project-shark.html       Shark project case study
css/styles.css           Visual styling + responsive layout
js/site.js               Menu, filters, video previews, reveals, contact behavior
assets/images/           Tiny Trek logo and project screenshots
assets/video/            Web-optimized project videos

PREVIEW
-------
Open index.html directly, or serve this folder locally with:
  python -m http.server 8000

Then visit:
  http://localhost:8000
